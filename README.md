# VideoClip - 拍打声智能声学识别与精准定点剪辑合并系统

基于 **Librosa 瞬态声学特征分析** 与 **FFmpeg 硬件编解码** 的音视频剪辑系统。
能够自动识别视频中的抽打/拍打声（人体皮肤），精准定位拍打时刻并自动截取前一秒与后一秒（[-1.0s, +1.0s]）区间，支持多重重叠合并，并由 H5 网页控制台管理与播放。

---

## 一、核心功能特性

1. **精准拍打/抽打声学识别**：
   - 聚焦人体皮肤碰撞频带（200Hz ~ 5000Hz）的能量爆发。
   - 提取短时瞬态冲激包络（Onset Strength）、RMS 能量与频谱质心（Spectral Centroid）。
   - 内置高阻尼肉体碰撞的脉冲衰减判定，有效排除环境长音杂音。
2. **毫秒级时间戳定点提取与智能融合**：
   - 定位拍打瞬间 $T_{peak}$，默认提取 $[T_{peak} - 1.0s, T_{peak} + 1.0s]$。
   - 自动检测并合并小于间隔阈值的连续拍击区间，杜绝切片碎片化与画面抖动。
3. **高精度无缝视频切片与合并**：
   - 利用 FFmpeg 精确重编码裁剪关键帧，避免音画不同步或开头黑屏。
   - 极速合并生成适用于 Web 端直接串流的 H5 兼容 MP4。
4. **现代 H5 交互式管理面板**：
   - **波形图谱联动**：直观展示音频能量与黄色剪辑区间。
   - **双视窗 H5 播放器**：左侧原片精确定位，右侧成片即时播放与下载。
   - **人工微调支持**：可点击任意识别点试听，支持一键剔除误识点或动态重新计算合并。

## 二、项目目录结构

```text
videocli/
│
├── core/                       # 核心处理模块
│   ├── audio_extractor.py      # 音频高保真提取与视频元数据探测
│   ├── impact_detector.py      # 皮肤/肉体拍打声学特征分析与区间合并算法
│   ├── video_cutter.py         # FFmpeg 毫秒级片段截取与拼接流水线

│
├── web/                        # Web 控制台服务
│   ├── app.py                  # FastAPI 后端路由、异步任务与媒体流
│   ├── static/                 # 静态样式与交互脚本 (Wavesurfer.js)
│   └── templates/
│       └── index.html          # H5 管理控制台页面
│
├── storage/                    # 存储目录 (上传、提取音频、成片)
├── run.py                      # 一键启动入口
└── requirements.txt            # 项目依赖
```

## 三、快速启动与使用方法

### 1. 安装依赖环境
确保已安装 Python 3.10+ 及系统全局 FFmpeg：
```bash
pip install -r requirements.txt
```

### 2. 启动服务
在项目根目录下运行：
```bash
python run.py
```
程序将自动在浏览器中打开：`http://127.0.0.1:8000`

### 3. 操作流程
1. **上传视频**：拖拽或点击上传待处理的原视频文件；
2. **调节参数并分析**：可调节“灵敏度”（默认 0.60）及“拍前/拍后缓冲时间”（默认 1.0 秒），点击【开始识别音频拍打声】；
3. **预览与微调**：
   - 在波形图与事件列表中查看每个拍打点的时间戳、能量和置信度；
   - 点击列表中的任意拍打项，原视频播放器自动跳跃至对应画面；
   - 误识别的噪音点可点击红叉一键移除；
4. **合并成片**：点击【步骤 3: 合并成片】，系统将自动剪辑各片段并拼接，右侧播放器可即时预览成片并支持一键下载。
